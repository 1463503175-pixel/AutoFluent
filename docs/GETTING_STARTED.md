# Get started · AutoFluent

AutoFluent 面向已有的 ANSYS Fluent 保存解：以只读方式分析 `.cas.h5` / `.dat.h5`，无需为离线分析先连接 Workbench。

## 下载安装

1. 下载仓库中的 [**V2.10.5 Windows 发布 ZIP**](../AutoFluent_V2.10.5_Windows_x64.zip)。
2. **完整解压**，不要只把 `AutoFluent.exe` 单独复制到其他目录。程序需要同目录下的 `worker/`、`templates/` 等文件。
3. 在 Windows x64 中双击 `AutoFluent.exe`。若离线 Worker 提示缺少 Python 或依赖，请使用可用的 Python 环境安装 `numpy`、`h5py`（测试环境还使用 `pytest`）。
4. 在左侧「保存解分析」选择一份 `.cas.h5` 或 `.dat.h5`，查看识别到的配套文件和当前分析模式。
5. 先看结构/几何预检结果。自动晶圆识别不唯一时，使用模型配置缩小搜索范围，再在同一入口分析。
6. 分析结束后打开 HTML 报告。端口流量、压降、晶圆及挡板的状态独立展示；部分成功不等于文件损坏。

## 界面工作流

```text
工作台
 ├─ 保存解分析       选择 Case/Data → 预检 → 原生通量统计 → HTML
 ├─ 模型对比         并列查看 / 口径核验 / 可用时统一截面复算
 ├─ 连接工程         仅在线任务需要已打开的 Workbench
 ├─ 标准工况         预览 / 审核 / 明确确认后发布
 └─ 求解与任务       显式授权迭代，并保留任务状态
```

## 如何阅读报告

- **端口与质量守恒**：使用原生面通量，核对正向、反向和净质量流量。
- **晶圆片间与旁路**：只有几何配对与截面归属可信时才发布逐通道流量和 CV。
- **挡板**：真实开口身份与完整截面通量闭合分开核对，不能用截面碎片数代替孔数。
- **压力**：需注明来源、端口/测站位置以及平均方法。
- **模型对比**：相同工况不意味着任意百分比可直接比较；要检查实际截面、分区和对应关系。

## 配置和代码

版本 V2.10.5 的示例文件在 [`source/templates/`](../source/templates/)；分析入口代码在 [`source/worker/`](../source/worker/)。CLI 参数可从 `source/worker/af_h5_offline.py --help` 开始，使用模型配置前先运行 `--check` 检查格式。**预检配置格式不等于实际几何已经识别成功。**

## 现阶段明确限制

- V2.10.5 的 233 项 Python 测试属于合成/历史回归，**不是** 2.0 真实 FFF 全量通道、挡板孔或 Windows 实机验收。
- 26,011,622 面真实模型的完整晶圆、挡板与 32 GB 内存峰值需要在实际计算机上复核。
- 复杂网格、多相与无法确认的几何不保证自动出数；诊断结果比猜测物理数值更重要。
- 在线模式**不得**未经用户审核自行修改 Fluent 设置、初始化或启动迭代。
