# AutoFluent V2.10 通用化升级｜第一阶段代码检查点

生成日期：2026-11-10。基线：用户上传的 `AutoFluent_V2.9.3_Windows_x64(1).zip`。

## 本轮解决的具体问题

1. **配置模式绕过历史模型路径**：离线命令增加 `--config` 和 `--check`。配置在打开大型 H5 数组之前严格校验；即使 Case 文件处于名为 `11.9` 的目录，显式配置也只进入自适应计算核心，不会启动 11.9 专用脚本。失败则明确停止，不回退其他几何的物理结果。没有配置时原 11.9 专用路径未修改。
2. **几何分区输入**：增加 `af_model_config.py`、`identify_from_configured_wall_triangles`。在指定的互斥 Y 层/Z 排搜索区间内，仍从真实三角壁面识别晶圆厚度、相邻平面及常规通道。预期数量只能用于核验，不能产生统计数量。配套的交错排列合成 CFF 回归得到 32 片、24 个常规通道，与自动识别口径一致。此数字仅来自合成测试，绝非 2.0 模型的实际片数。
3. **分段原生通量**：自动检查 `results/<id>/phase-*/faces/SV_FLUX` 的唯一匹配、全局 Face ID 区间完整性、重复与缺段。支持单组或多个连续分段，读数按 131072 个面分块；组筛选先验元数据，不重复读取所有候选组。对稀疏压力等面数据的跨度读取也增加 65536 Face ID 限制。
4. **内存限制**：面节点连接、c0、坐标及原生通量读取改为分块填充，读前估算数组峰值并执行用户可配置预算（512—16384 MiB，默认 6144 MiB）。此为**保守预检和部分分块**，尚不是内存峰值实测或全面 out-of-core 算法，不可据此保证所有 24M Face 模型均可运行。
5. **空间标记与分区**：给原有片间通道添加唯一排内 ID、实际 X/Z 中心坐标和 X/Z 范围；JSON、CSV 同步输出；原有截面四个互斥分区、正向/反向闭合逻辑保留。
6. **同口径比较保护**：两份模型若识别的几何、截面、方法、入口流量、层级或通道数不兼容，不再计算可能误导的 CV/片间份额/压降差值；两列原始统计值仍可单独展示，所有比较仍标为候选。
7. **HTML 报告**：增加独立的 `af_report_v3.py`，只消费计算 JSON，不读取 HDF5 或控制 Fluent；按 2.0 参考 HTML 的深蓝封面、流量分区、空间曲线、孔位、压力、可信度、模型对比、下一轮检查与可折叠明细组织。单文件内嵌 CSS/SVG，无网络外链。缺失字段显示“未取得”，合成报告明确标注“合成数据测试”。保留旧 HTML 作为渲染失败时的回退。
8. **Windows 原生入口**：原有“选择 H5 · 直接分析”保持不变；同页增加“配置辅助分析（可选）”，选择 H5/JSON 后走显式配置模式，失败回传具体信息。不要求连接 Workbench。

## 已知限制与风险（重要）

1. 配置模式目前明确支持 `wafer_normal=x / flow=y(negative) / row=z`；其他轴向/方向**提前拒绝**，并未伪称全方向通用。
2. 真实交错重叠晶圆若 Z 排物理重叠，当前配置拒绝重叠区域，尚需扩展明确分界归属。
3. CFF 当前仍要求**单个网格块、三角面和四面体单元**；c0/c1 多块结构未通过支持测试；压力单元字段和部分网格临时数据尚未全部 out-of-core。
4. 挡板孔、板边与多静压测站仍沿用现有候选逻辑；没有完成所有几何的逐孔/板边实测验收，配置中的压力测站目前仅进行输入合法性校验，尚未接入物理求解。
5. 自动识别属于待核查候选，不得因流量闭合或低质量不平衡就认定收敛。
6. 跨模型统计缺乏同一物理工况、稳定残差及统一截面的独立证据时，禁止正式优化结论。本轮只增加阻断比较失配差异的规则。
7. Windows GUI 已编译，**尚未在真实 Windows DPI/界面状态机中验收**；不能据此声称 EXE 全功能现场可用。
8. 2.0 模板文件作为项目资料可阅读，当前 HTML 已根据其信息组织重建，尚未作逐像素样式对照。

## 用法

直接分析：`AutoFluent.exe → 保存解分析 → 选择 H5 · 直接分析`。

配置模式：`AutoFluent.exe → 保存解分析 → 配置辅助分析（可选） → 选择 Case/Data → 选择 JSON`。

CLI 配置预检（不读取大型 H5 数组）：

```powershell
python worker\af_h5_offline.py --config templates\geometry_config_example_staggered.json --check
```

CLI 保存解（只读 Case/Data）：

```powershell
python worker\af_h5_offline.py --file "C:\path\model.cas.h5" --config "C:\path\actual_geometry.json" --output-dir "C:\path\reports"
```

**注意**：`geometry_config_example_staggered.json` 只对应内部合成网格，严禁当作真实 ALD 2.0 模型的几何参数。
