# AutoFluent V2.10.4：晶圆、挡板、报告发布专项修改与验收

日期：2026-11-10。改动基于同一 AutoFluent 主线 V2.10.4 开发目录，保留 11.9 专用原生计算路径，不操作 Fluent / Workbench。

## 1. 本轮修复

### 晶圆真实壁面与几何失败定位

- `af_wafer_patches.py`：同一 X 平面可以保留多个独立的壁面片；三角形连通改为**共享网格边**，不再以共享单个顶点强行并片；不因不同片的投影包围盒重叠便提前丢弃。
- 厚度和 Y/Z 投影配对仍是**一对一**；多个厚度候选时拒绝发布晶圆结果并记录 `first_conflict_x_m` 与 `competing_thickness_m`；真实物理晶圆在相同 X 厚度区间且 Y/Z 占据重叠时拒绝重计。
- 每层诊断记录真实输入三角形、X 法向与空间筛选数量、连通面片数量、面积过滤、厚度候选、配对及各排片数/通道数。空间范围、孤立片和未知排归属不制造结果；`layers=[]` 不能静默作为完整成功。
- 自动和配置入口共用面片配对算法。`af_geometry_precheck.py` 也转发实际失败阶段和诊断字典。配置是筛选和核验条件，不是预置的片间结果。

### 挡板开孔与原生流量积分

- 新增 `af_baffle_openings.py`：从选择的板面真实三角网格边界识别**闭合孔轮廓**，上下板面都需找到空间对应孔位。只有真实轮廓可确认且通量积分片全部能够唯一归属时，才发布孔数、孔间 CV 和逐孔分布。
- 一个孔允许对应多个独立截面积分片；板外边缘通路和**板内无法匹配的积分片**单独记录，不重复计数；`孔 + 边缘 + 未归属 = 整个阶梯截面` 严格核验净通量。
- `af_adaptive_native.py`：列出所有板面候选坐标、宽度、间距和被选方案；若两个板面候选都合理，返回 `plate_candidate_ambiguous`。可用 `measurement.baffle_y_range_m`（米）限制筛选范围。
- 只有候选或轮廓不闭合时，状态为 `hole_outline_unverified`，可输出真实的完整截面流量与失败诊断，**不能把截面碎块数量充当真实孔数**。

### 文件发布与桌面重试

- 不再调用 `os.link()`；改为同文件系统暂存 + `os.replace()`。先保留完整 JSON/CSV，再独立生成与发布 HTML，旧报告不覆盖，返回路径只包含已成功提交的完整文件。
- HTML 生成或落盘失败：返回 `computed_export_failed`、真实计算状态与具体路径/异常；已经写出的 JSON/CSV 保留，不触发「文件结构损坏」降级。
- 新增桌面「仅重试 HTML 导出」：读取已有 `native_reports` 下已计算 JSON，不重新打开大型 Case/Data；也可运行 `af_render_saved.py` 命令行独立重生成报告。
- 报告首页展示晶圆逐阶段阻塞以及挡板选板/轮廓诊断；端口流量、压降和成功验证的物理结果保留。

## 2. 运行与数据限制

- Python 测试：**222 / 222 通过**（合成/历史格式测试，非 2.0 真实模型）。Go 测试与 `go vet` 通过；Windows x64 原生 GUI EXE 交叉编译完成。
- 新增和更新的案例：同 X 对齐双排、交错 Z 重叠、阵列外假壁面、真实实体碰撞、两个合法板面候选、两个物理孔对应多个积分片、板边通路、孔内未归属片，以及 HTML 保存失败后保留完整 JSON 并重生成 HTML。
- **尚未证明**真实 26,011,622 面 FFF 的晶圆 384 片/380 通道、210 孔识别，未取得 32 GB Windows 真实内存峰值、Windows 多 DPI GUI 实机测试和求解收敛证据。
- 单相三角面/四面体、X 法向晶圆/Y 主流方向仍是当前明确的计算支持范围。不同拓扑、缺少实体板面轮廓、真实面片相互重叠或不确定孔归属时，拒绝伪造数据。
- **注意**：实际 FFF 如仍出现晶圆配对失败，请提供新版本生成的「首个实际阻塞」及 `diagnostics`，特别是 `first_conflict_x_m`、`connected_patch_count`、`paired_wafer_count`、`rejected_by`，才能针对真实拓扑复核。

## 3. 复现测试

在源码目录运行：

```bash
python -m pytest -q

go test ./...
go vet ./...
GOOS=windows GOARCH=amd64 CGO_ENABLED=0 go build -ldflags '-H=windowsgui -s -w' -o AutoFluent.exe ./cmd/autofluent
```

Windows 环境下可用已安装的 Python 运行：

```powershell
python .\worker\af_render_saved.py --json "C:\Users\...\AppData\Roaming\AutoFluentV1\native_reports\native_adaptive_XXX.json" --output-dir "C:\Users\...\AppData\Roaming\AutoFluentV1\native_reports"
```

这一步 **不读取 Fluent H5**。完整报告仅引用 JSON 中真实统计记录。
