# AutoFluent V2.9.2 日志与状态修复验收

## 错误依据

截图中底部只读日志框多次重绘后存在多行重影。Win32 中 `ES_READONLY` 编辑框的颜色请求可能以 `WM_CTLCOLORSTATIC` 到达，而原程序对该消息使用了透明背景；只刷新文字不填充背景。

## 修复

1. 只读日志控件返回白色不透明画刷，文本用深色不透明绘制。
2. `SetWindowTextW` 之前规范化所有换行到 CRLF，限制屏幕日志最多 18 条，详细诊断保存在文件。
3. Fluent 探测失败时保留“WB 上次握手成功”的事实，但不将缓存身份当作当前实时可用。对所有在线写入操作继续要求最新 Fluent 身份验证。
4. 下一次点击连接按钮仍只核验用户输入的端口，不扫描其他端口、不启动 Workbench、Fluent 或 Server。

## 验收边界

纯 Go 日志规范化与状态测试、旧版 Go/Python 回归和 Windows x64 交叉编译可以在网页环境完成；实际 Windows GUI 绘制（不同 DPI、系统字体、不同原生窗口尺寸）、9935 真机通信仍需要本机运行验证。
