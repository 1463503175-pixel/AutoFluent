# AutoFluent V2.9.3：报告可读性、数值核验与来源边界

## 1. 问题与修复

- V2.9.1 的 Windows 只读 EDIT 日志会在重绘时重影；V2.9.2 对 `WM_CTLCOLORSTATIC` 中的只读 EDIT 使用不透明白色背景，并将主界面日志限定为简短状态。相关修复沿用至 V2.9.3，Linux Go 回归与 Windows 交叉编译通过，实际 Windows DPI 下仍需验收。
- 旧 H5 报告将 HDF5 索引、网格拓扑、通量候选、真实几何计算混在一起；使用者需翻阅技术日志才能看到主要结果。V2.9.3 新增 `worker/af_report_summary.py`，每份生成的 HTML 先呈现「一页看懂」关键结果，然后保留全部原始明细。
- 严格 11.9 脚本 `af_native_11_9_reference.py` 未改变：原脚本产出的 HTML 不覆盖；由 `af_native_profile.py` 追加生成独立 `.summary.html`，默认报告按钮打开新汇总页，原始 `.html`、`.csv` 和 `.json` 均保留。
- 自适应几何分析的 HTML 顶部插入汇总及未核验标记，逐通道曲线与正反向通量仍在后面。
- H5 仅完成结构索引、无法正确识别实际通道时，汇总明确显示「未取得」，不会擅自写入 CV 或压降。

## 3. 自动生成的报告形式

第一部分「一页看懂」：分析等级、入口/出口、流量差、压降、挡板、集气腔和上下层片间/旁路表；自适应模式明确标「候选值」。

第二部分「结果解读」：仅计算上下层 CV/片间占比差值，不自动判定哪种模型更优；两层串联截面禁止相加。

第三部分「分布图与原始明细」：保持每通道分布、原始通量表、方向性通量、截面敏感性、来源与限制。

## 4. 验收边界

- Python 单元/合成 H5 端到端与历史 CSV 回归、Go 测试、Vet、Windows 交叉编译可在当前环境完成。
- 与实际 H5 的几何适配、Fluent 2024 R2 Workbench TUI 实机状态和 Windows DPI 布局仍需在用户电脑验收。
- HTML 可以是一个有效的**诊断报告**，但若没有真实片间截面和独立核验，不能等同于有效的物理统计报告。
