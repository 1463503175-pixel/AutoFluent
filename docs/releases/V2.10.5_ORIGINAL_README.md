# AutoFluent V2.9.1 — 操作流程与界面修正版

**定位**：让 ALD 仿真分析变得更快，而不是让使用者维护 Python、端口、JSON 和中间报告。主入口是保存解 `.cas.h5 + .dat.h5`；Workbench 只用于确实需要控制已打开 Fluent 的任务。

## 两条互不依赖的主流程

1. **保存解分析（默认）**：解压后运行 `AutoFluent.exe` →「保存解分析」→「选择 H5 · 直接分析」→自动配对 Case/Data、读取原生数据并生成报告。第二份模型分析完成后，到「模型对比」核对口径、计算差异。无需 WB 端口，也无需 Codex 报告。
2. **在线控制（需要时）**：在当前 Workbench 命令窗口执行 `StartServer()`，把返回的端口填入「连接工程」。连接成功后，软件使用已验证的 Workbench 会话识别 Fluent；随后可在「标准工况」导出/审核 `.set`，或在「求解与任务」明确授权有限迭代。

左侧导航顺序是：**工作台 → 保存解分析 → 模型对比 → 连接工程 → 标准工况 → 求解与任务**。屏幕上不再暴露旧的重复 PyFluent 技术配置控件，完整错误可以通过「打开完整连接诊断」查看。

## 本次有实际代码修复的项目

- 修正 WB 已成功握手后，Fluent 检查可能把 Python 的 `Starting gRPC client without TLS` **警告误判为 JSON 格式错误**的问题。WB/Fluent、`.set`、监控等回执统一使用容错解析，不把警告视为成功。
- 修正首页状态和按钮、标准工况按钮、全局日志、模型对比输入框的重叠和排列；布局按内容区及系统缩放计算，并增加尺寸回归测试。
- 只在报告存在时启用「查看本次报告」；清单不覆盖实际分析报告；比较输入缺失或 WB/Fluent 连接未验证时禁用相应按钮；发布需要完成审核并输入指定确认文字。
- 页面状态只反映当前工作流，离线保存解分析页不再显示无关的 WB 旧错误。

**状态边界**：真实 Windows 多 DPI 可视化、用户 WB 端口的真机联机、11.9 大型 H5 和不同模型的物理结果仍需要现场验收；Go/Python 离线测试不能证明这些已经完成。

详见 `docs/V2.9_六页面与按钮验收.md`。


## V2.9.1 Workbench → Fluent 识别修正

- 修复实际存在的 **假零系统** 问题：旧版把 `GetFluentLauncherSettings()` 当成识别 Fluent 必需条件；该 API 对当前编辑器报错时，已打开的 Fluent 也会被过滤。
- 现在先枚举 Workbench 所有系统，再以 Fluent 相关系统标签及已有 Setup/Solution 容器识别候选；仅有候选还不能控制 Fluent，必须继续成功提交只读 TUI 探测。
- 当 WB 已连接但未识别 Fluent 时，保留当前 WB 工程文件路径、**所有原始系统**名称和数目；能区分“连错 WB 工程”和“识别器漏掉 Fluent”，不会再只有“Fluent 系统数 0”。
- 仍然使用输入的指定端口，无端口搜索、无 `StartServer()`、无新 Fluent/Workbench、无初始化或迭代。
- **真机验收未完成**：程序需要在用户当前的 ANSYS Workbench 2024 R2 和 Fluent 编辑器实际测试；合成系统测试不等于真实工作流已连通。

验收建议：从原 WB 执行 `StartServer()` 返回端口，AutoFluent 输入该端口。连接页日志现在应显示同一 WB 工程路径及原始系统（例如 A / Fluid Flow (Fluent)）；若识别到目标但 TUI 未验证，则查看新的探测错误，不能自动重试有副作用的命令。


## V2.9.2 针对性修复

- **底部日志重影**：Windows `EDIT` 控件设为 `ES_READONLY` 后，会通过 `WM_CTLCOLORSTATIC` 请求背景画刷。旧实现返回透明背景，导致长日志刷新时残影叠字。本版对只读日志编辑框设置白色不透明背景。
- **日志行格式**：将 Python 不规则的 `LF/CR/CRLF` 统一为 Win32 编辑框需要的 `CRLF`，限制界面日志的数量与长度。完整诊断仍在 `wb_last_connection_diagnostic.txt`，没有丢失底层异常信息。
- **Workbench/Fluent 状态**：WB 上一次成功的握手和本次 Fluent 检查失败分别展示。失败不代表端口已失效，但在重新验证前仍禁止远端写操作。
- **窗口现状**：本次已完成编译及离线代码测试，但无法在 Linux 容器里真正显示你的 Windows DPI/字体环境，因此实际重影是否完全消失需要本机窗口验收。

**使用方式**：完整解压新版后运行 `AutoFluent.exe`。进入连接工程输入当前有效的 Workbench 端口，不用修改 Python、Fluent 或 Case/Data。完整错误点击“打开完整连接诊断”。
